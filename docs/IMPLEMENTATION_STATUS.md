# 实施状态

更新时间：2026-08-18

## 已完成的工程基线

- 真实 MySQL 数据源新增、凭据 AES-256-GCM 加密、物理只读测试和数据源切换。
- API 驱动工作台；真实源无静态结果回退，缺 LLM/本体/JOIN 时明确拒答。
- 受限探针、A/B/C 分级、敏感字段前置隔离、显式/隐式关系与证据化消歧。
- SQLite + Markdown 知识资产、verified 保护、术语/指标优先召回与 Wikilink 扩展。
- 业务对象 Schema V1：Object Type、类型化 Property、Link Type、物理字段/JOIN 映射、聚合错误校验、不可变版本与重新校验发布。
- 业务对象建模工作台：结构化对象/属性/约束/关系编辑、物理表/字段/JOIN 选择、失效映射提示、版本 Diff、JSON 高级模式、角色只读限制、保存和发布闭环。
- AI 辅助本体建模 M0–M4 工程基线：服务端同源范围预算预览、有界 Object/Link 候选生成、超宽表截断与敏感/失效 JOIN 过滤、确定性评分、人工审核、草稿 Diff/组装、受限模型留痕，以及目录防漂移、双人独立校准、发布后 Gold 评测集防漂移、精度/召回/运行预算与 `auto_draft` 启用门禁；校准看板可核对评测集完整度并直接触发、跟踪当前发布 Schema 的 Gold 语义门禁。
- 本体证据增强 v0.2：可灰度启用的脱敏列画像、关系 overlap 前置、已核验知识注入、关系文档 `review` 桥接、Object 画像/枚举提示、v2 连续评分、critic 强制人审降级、同评分版本校准、逐数据源阈值建议/采纳审计，以及知识页 embedding top-K 回退链路。
- 可交互本体关系图谱：发布版 Object/Property/Link、对象到物理表映射、知识绑定、真实 JOIN 与 Wikilink，支持业务语义/物理映射视图切换、搜索、筛选、缩放、平移和节点详情。
- LLM → 字段/表/JOIN/枚举 AST Guard → EXPLAIN → 执行 → 两次修复 → 审计主链路。
- 问数字段与会话上下文增强：问数链路不再因 `isSensitive` 限制字段检索、输出、过滤、聚合或采样；手机号等格式值会与字段语义匹配校验，短追问携带最近用户纠正和历史表范围，Legacy、Agent、语义计划与评测策略已统一。
- 问数 Loop V2：已加入 QueryIntent 意图保真、机构实体连续匹配、时间约束检查、知识页与结构候选并集合并、英文扩展词边界保留、业务根表加权、同名字段/枚举精确归属、`resolve_entity`、检索成功后状态强制推进、重复动作无进展熔断、未知表真实目录建议、结构化失败分类、LIMIT 完整性检查、审计版本字段及重复动作评测门禁；已增加真实目录 Gold 就绪检查、审核/最小规模/幂等导入保护及 `prefer` 会话级灰度比例，生产默认模式仍等待 30 题正式 Gold 集通过后放量。
- 仅保存结构标识的多轮会话，不持久化历史问题、SQL、结论和结果。
- 持久化异步探查/评测任务、重启恢复、Schema 快照与非破坏性增量失效。
- 评测 CRUD、软归档、Held-out 隔离、结果集等价和失败知识修复建议。
- 角色/数据源范围鉴权、Bearer token、限流、CORS、安全响应头和请求 ID。
- Docker Compose、持久卷、只读根文件系统、健康检查和备份恢复说明。

## 自动化证据

- `npm run lint`
- `npm test`：安全、存储、检索、真实查询编排、异步恢复、Schema 历史、业务对象图谱、鉴权限流和评测。
- 语义 Schema 自动化覆盖合法映射、多错误聚合、候选 JOIN 拒绝、版本发布切换、角色权限和 422 校验响应。
- 版本 Diff 自动化覆盖兼容新增、破坏性删除、字段映射变化，以及目录与 Diff API。
- `npm run build`
- `npm run test:rendered`
- 隔离临时 SQLite/API 烟测：鉴权、bootstrap、202 异步任务、任务完成和 Schema Diff。

## 需要部署方提供后才能完成的业务验收

1. 真实 MySQL 只读副本及网络白名单。
2. 可用的 OpenAI-compatible LLM endpoint、模型名和已轮换的 API key。
3. 首期业务域表范围、术语/指标负责人、30 题冒烟集和 100+ 完整集。
4. 企业 SSO/密钥管理选型；当前角色 token 是可替换的本地生产基线。
5. 目标并发、响应时间 SLO、生产备份恢复演练窗口。
